

Autism Detection Web Application Using Machine Learning
A web-based application for preliminary screening of Autism Spectrum Disorder (ASD)-related traits using an AQ-10 behavioural questionnaire and a Random Forest machine learning model.
Important: This application is intended for educational, awareness, and preliminary screening purposes only. It does not diagnose autism and must not replace assessment by a qualified healthcare professional.

Project Overview

The application provides a simple interface through which users can create an account, log in, enter demographic information, complete an AQ-10 behavioural questionnaire, and view a screening result generated by a trained machine learning model.

The system combines a Flask web application with a Random Forest classifier. It displays the screening outcome, an estimated prediction probability, and an appropriate recommendation.

How the Application Works

1.A user registers and logs in.
2.The user opens the dashboard.
3.The user enters the requested demographic details and completes the AQ-10 questionnaire.
4.The Flask backend receives and prepares the submitted input.
5.The prepared input is passed to the trained Random Forest classifier.

Machine Learning Approach

The project uses a Random Forest classification model trained on behavioural and demographic information. The application uses the AQ-10 questionnaire responses and relevant demographic inputs to generate a preliminary screening prediction.
The trained model is saved using Pickle and loaded by the Flask application when a prediction is requested.
The project report describes data preparation steps including removal of irrelevant fields, handling missing values, encoding categorical data, feature selection, and splitting the data into training and testing sets.


Dataset

The project report describes the use of a publicly available Autism Screening Dataset. The interim report records 704 data records and 21 attributes.
The application uses behavioural questionnaire responses and demographic information as model inputs. Dataset quality and representativeness affect the reliability of model outputs.
